# Laboratorio de Ciberseguridad - Jserna

## Descripción
Proyecto académico orientado al estudio de la
ciberseguridad, el reconocimiento de amenazas
y el análisis de vulnerabilidades en entornos controlados.

## Estructura del proyecto

| Módulo | Descripción |
|---|---|
| 00-servidor-dmz | Servidor web de pruebas |
| 01-ataque-dos | Simulación de tráfico HTTP |
| 02-escaneo-puertos | Reconocimiento de puertos |
| 03-fuerza-bruta-rutas | Enumeración de rutas |
| 04-exfiltracion-dns | Demostración de consultas DNS |
| 05-cadena-suministro | Simulación de dependencia comprometida |
| 06-credential-stuffing | Análisis de autenticación |
| 07-proxy-mitm | Demostración de intermediación HTTP |

## Tecnologías utilizadas

- Python
- Docker
- Shell Script
- Flask
- GitHub
- Render

## Objetivo

Comprender diferentes escenarios de seguridad
informática mediante simulaciones controladas,
identificando riesgos y posibles mecanismos de protección.

## Consideraciones de seguridad

Este laboratorio es exclusivamente académico.
Las pruebas deben realizarse en entornos aislados,
con autorización y sin afectar servicios de terceros.
